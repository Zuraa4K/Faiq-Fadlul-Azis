FAIQ FADLUL AZIS — PERSONAL WEBSITE

Isi folder:
- index.html : website utama
- robots.txt : petunjuk crawling untuk mesin pencari
- sitemap.xml : daftar URL untuk Google

SEBELUM PUBLISH:
1. Ganti semua teks https://GANTI-DENGAN-DOMAIN-KAMU dengan domain final kamu.
2. Tautan sosial sudah diisi: TikTok @zuraav, YouTube @zuradelmora, Instagram @paiqch_. Pastikan URL YouTube sesuai dengan handle akun yang aktif.
3. Periksa deskripsi proyek agar hanya memuat pekerjaan yang benar-benar kamu lakukan.
4. Tambahkan foto profil milikmu sendiri dan sesuaikan og:image jika sudah tersedia.
5. Upload file ke hosting (misalnya GitHub Pages atau hosting sendiri).
6. Setelah domain aktif, verifikasi domain di Google Search Console, kirim sitemap.xml, lalu gunakan URL Inspection untuk meminta pengindeksan.

CATATAN:
- Tidak ada jaminan Google akan langsung mengindeks atau menampilkan Knowledge Panel.
- Jangan masukkan alamat rumah, nomor identitas, atau data pribadi sensitif ke website publik.
